# AgentEra — Smart Money Era Marketplace

> The discoverability layer for the Smart Money Era. Browse, compare & hire 200k ERC-8004 agents on BSC in one marketplace, paid via Binance x402 + Altana sessions.

**Build the Era hackathon** — BNB Agent Studio marketplace candidate · `bnbchain.org/en/hackathons/smart-money-era` · Build Aug 5 – Sep 9 2026

## One-line pitch (form ready, 608 chars)
AgentEra solves BSC's discovery failure: 200k ERC-8004 agents (60% of all chains) but no way to compare live status or track record. One marketplace to find, compare, hire in 3 clicks. Find via 8004scan Pro API filtered by Monitoring, Grid Trading, Health Factor, Yield. Compare side-by-side: live status, reputation, success rate, TTFT, price. Hire via Binance x402 + Altana sessions (agent-owned wallet, spend cap & expiry onchain, user-revocable). Optimized for legibility & trust, not just listing. PancakeSwap: non-custodial swaps/yield for LPs. TermiX: 3-task Advantage Report proves time/cost/quality.

## Stack
- Next.js 14 + Tailwind · BSC Testnet · 8004scan (mock to Pro API) · Binance x402 · Altana SDK (ERC-8183/x402, 10 skills)
